# Voyage Analytics — Integrating MLOps in Travel

**Made by Santosh Kumar**

Capstone project: end-to-end ML system for the travel & tourism domain, covering
flight price regression, gender classification, and hotel recommendation — plus
the full MLOps stack to serve, containerise, orchestrate, and monitor it.

**GitHub Repository:**  https://github.com/sant8ntl-max/SKVoyage_Analytics_MLOps_Travel-1-


---

## Project Overview

| Problem | Type | Model |
|---|---|---|
| Flight price prediction | Regression | Random Forest / Linear Regression |
| User gender prediction | Classification | Random Forest / Logistic Regression |
| Hotel suggestions | Recommendation | Content-based (cosine similarity) |

## How to Run

### 1. Train the models (Colab or local Jupyter)
Open `Voyage_Analytics_MLOps_Travel.ipynb`, upload `users.csv`, `flights.csv`,
`hotels.csv`, and run all cells. This produces the `artifacts/*.pkl` files used
by the API and the Streamlit app.

### 2. Run the REST API locally
```bash
pip install -r requirements.txt
python app.py
# API available at http://localhost:5000
```

Example request:
```bash
curl -X POST http://localhost:5000/predict \
  -H "Content-Type: application/json" \
  -d '{"from":"Recife (PE)","to":"Florianopolis (SC)","flightType":"firstClass","agency":"FlyingDrops","time":1.76,"distance":676.53,"month":9,"dayofweek":3}'
```

### 3. Run with Docker
```bash
docker build -t voyage-flight-price-api .
docker run -p 5000:5000 voyage-flight-price-api
```

### 4. Deploy to Kubernetes
```bash
kubectl apply -f k8s-deployment.yaml
```

### 5. CI/CD with Jenkins
Point a Jenkins pipeline job at this repo — it will pick up the `Jenkinsfile`
automatically and build → push → deploy on every commit.

### 6. Schedule retraining with Airflow
Copy `dags/travel_pipeline_dag.py` into your Airflow `dags/` folder. It retrains
the model weekly (`@weekly`).

### 7. Run the Streamlit app
```bash
pip install streamlit
streamlit run streamlit_app.py
```

## Datasets

- `users.csv` — user code, company, name, gender, age
- `flights.csv` — travelCode, userCode, from, to, flightType, price, time, distance, agency, date
- `hotels.csv` — travelCode, userCode, name, place, days, price, total, date

`travelCode` and `userCode` link the three datasets together.
